This is a project dedicated to creating a highly customizable music player that will let the user decide the experience.
It allows the user to save their preferences and have the most optimized version of their dedicated music player.
Nontheless, it is a lite project only intended to show how easy it is to have the best experience through devices without having to pay for a subscribtion.

Why I started this project:
The idea of a subcribtion system is to have the ease of not having to deal with things. 
With the current developments in both the UK and USA (California AB1043), the aggressive implementations of age verification through collecting official ID documents as such;
I have deducted that as a internet user, everyone has an obligation to change the current capilized state of the internet.

This project is able to;
Play music files locally, change multiple themes (10+), Create and save playlists, Save your very own preferences in a condensed .json file,
